# Skill-Gap-Analyzer
Learn Depth ML Internship project -1
🎯 Skill Gap Analyzer
Project Overview
The Skill Gap Analyzer is a Python-based web application designed to compare a candidate's current skill set against specific job role requirements. It provides an instant, prioritized report highlighting matched skills, core missing skills (high priority), and bonus missing skills (medium priority).
Technical Implementation
 * Frontend Framework: Built a responsive, interactive web dashboard using the Python streamlit library.
 * Data Structure: Utilized a Python dictionary to act as a lightweight mock database, categorizing role requirements into "Must-Have" and "Nice-to-Have" tiers.
 * Core Logic: Leveraged Python set operations to efficiently calculate the mathematical intersection (for matched skills) and differences (for missing skills) between the user's input and the database requirements.
 * Input Handling: Implemented string formatting methods to clean user data and prevent case-sensitivity errors.
How to Run the Application
 * Ensure Python is installed on your system.
 * Install the required web library by running: pip install streamlit
 * Navigate to the folder containing the script and run: streamlit run app.py
